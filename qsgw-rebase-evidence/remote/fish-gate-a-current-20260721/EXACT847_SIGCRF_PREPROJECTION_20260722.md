# exact847 real-space Sigma preprojection comparison

## Result

The accepted current executable recomputed the Si k444 symmetry-on,
shrink-chi-off, no-head, no-Hartree one-update case and exported all 16
real-space `SigcRF` files. The immutable artifact is:

`/home/bhj/ai-runs/librpa-qsgw-gate-a1-exact847-current-sigcrf-compare-20260722-087f29fb-v1`

Direct comparison with the usable exact847 iteration-1 prefix found:

- identical file keys, block shapes, and 16-frequency coverage;
- 4,096 atom-pair/R/frequency blocks and 1,982,464 complex elements;
- maximum absolute difference: `5.018888896315565e-4 Ha`;
- relative Frobenius difference: `5.168509507718021e-3`;
- largest entry at spin 0, frequency index 10, `R=(0,0,0)`, AO `(0,0)`;
- differences in all 64 real-space cells, not only the onsite block.

A best global complex rescaling leaves a relative residual of
`5.14485e-3`, so this is not explained by one unit or normalization factor.

## Localization

The separate restart/projection probe feeds the exact847 `SigcRF` files into
the current reader and k-local BLACS projection. It reproduces the exact847
fixed-basis `SigmaC(iw)` to `2.73e-10 Ha` maximum absolute and `1.34e-10`
relative Frobenius difference. Therefore the ordinary one-update mismatch is
already present in the real-space Sigma generated by the shared G0W0 builder;
it is not introduced by the QSGW fixed-basis projection.

The runtime logs expose a structural version difference:

- exact847: IBZ q-stars -> irreducible-sector `W(R)` -> symmetry restore;
- upstream `42d3863c`: IBZ q-stars -> full `W(R)` directly.

The latter path entered upstream in commit `318e3e42` (`Fix kBLACS symmetry
restoration from IBZ mean fields`). This correlation does not by itself prove
causality or establish which result is physically correct. A diagnostic-only
A/B build restores just the old q-to-R accumulation in an isolated source
copy; no shared GW/EXX source change is accepted into the QSGW branch.
